# InferRef 0.12.2

Released — 2026-11-13

This patch refreshes the PyPI project page and install metadata. It is
wire-compatible with 0.12.1; no Trace IR, testcase, adapter or CLI behavior
changed.

## Install

Python 3.10 or newer is required.

```bash
python -m pip install inferref==0.12.2
```

The core package depends on numpy only. Install the tracing frontend or Agent
MCP integration separately:

```bash
python -m pip install "inferref[torch]"
python -m pip install "inferref[agent]"
```

The GitHub Release also carries `inferref-cpp-0.12.2.tar.gz` for the header-only
C++ SDK and `inferref-skill-0.12.2.tar.gz` for the Agent skill, plus
`SHA256SUMS`.

## What changed

- README links are absolute GitHub URLs, so they work from the PyPI project
  page.
- Added package classifiers and project URLs for Python versions, license,
  documentation, repository and issue tracking.
- Installation hints use cross-platform double quotes; `inferref doctor` points
  to the `torch` extra when PyTorch is unavailable.
- Distribution installation checks now run `inferref doctor --json` for both
  the wheel and sdist.

## Compatibility

- Wire-compatible with 0.12.1; existing traces, testcases, adapters and
  artifacts remain readable.
- No dependency or optional-extra changes.

## Validation

The release gate covers the Python test suite, the distribution install checks,
the C++ suite, and branch/tag CI. Published wheel and sdist hashes match the
GitHub Release `SHA256SUMS`.

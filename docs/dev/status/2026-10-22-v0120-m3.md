## 5. Caveats and unverified items

- **Serial-prefix narrowing only.** The ≤8-evaluation binary-search bound assumes
  a serial-prefix runner. If a runner only fails the exact faulty child region
  (containment-only), a passing midpoint is not a valid prefix bound. The code
  and tests implement the approved SPEC §7.2 assumption; release notes must not
  generalize the bound.
- **M4 is P1.** The multi-bug Agent benchmark and `--diagnostic-mode` are not in
  the 0.12.0 P0 gate unless the user promotes them.
- **Linux/WSL.** WSL is disabled. All Linux verification (core/frontend/agent/
  C++ jobs) is deferred and not claimed.
- **Remote CI.** GitHub is unreachable from this host; CircleCI/GitHub Actions
  results and tag/release state are unverified.
- **A770 0.12 gate.** Passed on `bd0b28e`: 13/13 positive cells and 3/3
  deliberately corrupted cases, A770 / Level Zero / driver `1.17.39894+4`.
  The later I2b-2b2 guard and release prep are Python/docs-only; no SYCL/C++
  engine input changed.
- **Slow tests.** The three slow installation tests pass on the final tree
  (`3 passed`).
- **Distribution/version.** Version is `0.12.0`; the final wheel/sdist build,
  check and install pass (`inferref --version` prints `inferref 0.12.0`).

## 2. WSL proxy correction

The local WSL `~/.zshrc` `clashon` helper now points at the current mirrored
Windows proxy endpoint:

- `http.proxy` / `https.proxy`: `http://127.0.0.1:7897`
- `https_proxy` / `http_proxy`: `http://127.0.0.1:7897`
- `all_proxy`: `socks5://127.0.0.1:7897` (the endpoint accepts SOCKS5)
- Original file backed up as `~/.zshrc.bak-20261113-144840`.

`zsh -lic 'clashon; ...'` now sets the proxy variables and WSL's global git
proxy to `127.0.0.1:7897`; an HTTP CONNECT test to
`https://test.pypi.org/simple/` returns 200. The earlier note that `.zshrc` still
contained the stale `172.31.224.1:7897` address is therefore historical.

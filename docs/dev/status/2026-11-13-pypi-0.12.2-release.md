## 5. Release contents

0.12.2 is a metadata/documentation patch:

- absolute GitHub links in README, including PyPI-rendered docs/examples links
- classifiers and `[project.urls]`
- cross-platform double-quoted install hints
- `inferref doctor` remediation points to `inferref[torch]`
- distribution install checks now run `inferref doctor --json`

No Trace IR, testcase, adapter, wire-format or runtime behavior changed.
